# Windows 사진 얼굴 교체 프로그램

## 목적과 완료 기준

사용자는 Windows와 RTX 3080을 사용하며 아직 Stable Diffusion을 설치하지 않았다. Python 데스크톱 프로그램에서 얼굴 원본 사진과 대상 사진을 선택하고 얼굴을 교체한 뒤 결과를 저장한다. 선택 기능으로 Stable Diffusion을 사용해 교체 경계를 보정한다. 기존 kohya_ss 코드는 없으므로 이 저장소에서 독립 프로그램을 시작한다.

## 접근 방식

1. 권장: 전용 얼굴 교체 모델과 선택적인 Stable Diffusion 인페인팅을 결합한다. 원본 얼굴의 정체성을 유지하면서 보정 비용을 선택할 수 있다.
2. Stable Diffusion만 사용: 설치할 모델이 크고 정체성 유지에 추가 장치가 필요하다.
3. 기존 웹 UI 확장: 기존 도구 설치와 실행이 필요하며 독립 데스크톱 프로그램이라는 요구와 맞지 않는다.

## 첫 버전의 사용자 흐름

Tkinter 창에서 얼굴 원본 사진과 대상 사진을 선택한다. 탐지된 얼굴을 번호와 미리보기로 보여주고 각각 하나를 선택한다. 교체 버튼으로 백그라운드 작업을 시작하고 진행 상태와 오류를 표시한다. 결과를 미리 보고 사용자가 지정한 경로에 PNG로 저장한다. 원본 파일은 덮어쓰지 않는다. 동영상, 웹캠, 일괄 처리는 첫 버전에 포함하지 않는다.

## 구성과 모델

UI, 이미지 입출력, 얼굴 탐지·교체, 선택적 보정, 모델 준비 기능을 분리한다. InsightFace와 ONNX Runtime GPU를 얼굴 탐지·교체 후보로 사용하되 실제 모델의 배포 출처·사용 조건·호환성을 확인한 후 확정한다. 검증 가능한 모델 공급 경로가 없으면 우회 다운로드를 만들지 않고 모델 준비를 차단 상태로 표시한다. 상업적 이용 가능 여부는 라이브러리와 모델을 각각 확인해야 한다.

Stable Diffusion 보정은 별도 설치 가능한 기능으로 제공한다. Diffusers의 SD 1.5 인페인팅 계열을 후보로 하며 로컬 얼굴 경계 마스크와 낮은 보정 강도를 사용한다. 보정 끄기를 기본값으로 하고 얼굴 교체 결과 자체도 보존한다. RTX 3080의 10GB·12GB 변형을 고려해 FP16, 순차 모델 로딩, 작은 보정 영역을 사용한다. 모델 크기와 다운로드 출처를 표시하고 필요한 다운로드는 사용자가 명시적으로 실행한다. 사진을 원격 추론 서비스로 보내지 않는다.

## Windows 설치와 실행

지원 Python 버전을 의존성 호환성 조사 후 고정한다. 가상환경을 만드는 설치용 배치 파일과 프로그램을 시작하는 실행용 배치 파일을 제공한다. GPU 런타임 호환성을 점검하고 CPU로만 실행되는 경우 이를 표시한다. EXE 패키징은 Python 실행 검증 이후 단계로 둔다. EXE에는 대용량 모델을 포함하지 않는다.

## 오류 처리

이미지 읽기 실패, 얼굴 없음, 잘못된 얼굴 선택, 모델 누락, GPU 메모리 부족, 다운로드 실패를 구분한다. 처리 중 UI가 응답하도록 작업 스레드를 사용하고 중복 실행을 막는다. 결과가 완성되지 않으면 성공으로 표시하지 않는다. 로그에는 사진 데이터나 인증 값을 기록하지 않는다.

## 검증

실제 의존성 설치와 모델 로딩을 확인한다. 파일 읽기·저장, 얼굴 선택, 오류 전달과 작업 상태 전이를 테스트한다. 공급 가능한 모델과 사용 허가가 확보된 테스트 사진으로 CPU 얼굴 탐지·교체를 실행하고 실제 이미지 출력을 확인한다. 다운로드나 모델 접근이 막히면 해당 검증을 미실행으로 기록한다.

현재 클라우드는 Linux이며 NVIDIA GPU가 확인되지 않았다. Windows GUI, RTX 3080의 CUDA 실행, Stable Diffusion 보정 화질, EXE 실행은 Windows GPU 장비에서 별도로 검증해야 한다. 클라우드 검증만으로 이 항목들이 통과했다고 보고하지 않는다.

## 재사용 환경 설정

실제 실행해 검증한 설치 명령만 install_script에 저장한다. start_skill에는 기존 /workspace/kohya_ss 체크아웃 사용, 별도 worktree 불필요, 환경 활성화, 모델 준비 상태 확인, 검증과 실행 절차를 기록한다. 실행 중인 프로세스가 다음 작업에 유지된다고 가정하지 않는다.
