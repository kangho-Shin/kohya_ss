Office Power 현장 점검 도구 사용법

1. 이 폴더 전체를 PC로 복사합니다. CMD와 PS1을 함께 두세요.
2. Field-Tools.cmd 더블클릭 → 관리자 권한 승인.
3. 메뉴 번호를 입력합니다. PowerShell 명령어 입력은 필요 없습니다.

관리 PC에서:
  1: 대상 PC의 IP를 입력해 연결을 검사합니다.

문제가 있는 대상 PC에서:
  2: 서비스·IP·MAC·네트워크 종류·방화벽·포트·등록 파일 위치를 확인합니다.
  3: 신뢰하는 현장 유선 LAN의 번호를 골라 Public을 Private로 바꿉니다.
     선택한 연결만 변경합니다. YES 입력은 적용, Enter는 취소입니다.
  4: 중지된 Agent 서비스를 시작합니다. YES 입력 후 실행합니다.
  5: 랜카드 설정 화면을 엽니다. Magic Packet은 직접 설정합니다.
  6: 전원 옵션을 엽니다. 빠른 시작은 직접 해제합니다.
  0: 종료합니다.

결과는 옆 Reports 폴더에 PC 이름·시각별 TXT로 저장됩니다.
실패하면 표시된 오류를 확인하세요. 다른 PC 설정을 원격 변경하지 않습니다.
로그에는 IP·PC 이름이 있으므로 내부 진단용으로 보관하세요.
BIOS 설정은 대상 PC의 BIOS 화면에서 변경해야 합니다.
설치·업데이트·제거는 AgentSetup.exe를 사용하세요.
