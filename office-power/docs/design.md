# 사무실 PC 전원 관리 설계

작성일: 2026-10-20 (한국 시간)

## 목적
동일한 사무실 LAN에 있는 여러 Windows PC를 C# 데스크톱 관리 프로그램에서 켜거나 끈다. 대상 PC마다 작은 제어 프로그램 설치를 허용했다. 기존 얼굴 교체 프로젝트와 별도로 office-power/에 솔루션을 둔다.

## 범위와 사용 흐름
관리자 PC에서 PC 이름·IPv4·MAC 주소를 등록하고 대상 서비스가 발급한 인증 파일을 가져온다. 목록에서 하나 또는 여러 PC를 선택해 켜기 또는 끄기를 실행한다. 등록 목록은 다음 실행에도 유지한다. 원격 데스크톱, 화면 감시, 파일 전송, 임의 명령 실행, 재부팅은 포함하지 않는다.

## 접근 방식
사용자 요청에 따라 WinForms 관리 앱, Windows 서비스 에이전트, 공유 코어 라이브러리로 구성한다. Windows 원격 종료만 사용하는 대안은 계정·정책 설정이 복잡하다. 에이전트 없는 전원 켜기만으로는 종료 요구를 해결하지 못한다.
Visual Studio 2022·WinForms/.NET 8·C# 12와 기본 .sln 솔루션 형식을 사용한다. MainForm과 RegistrationForm의 배치는 .Designer.cs로 분리한다. self-contained Windows x64 배포 폴더를 제공한다. 대상은 Windows 10/11 x64이며 별도 .NET 설치 없이 배포물을 사용할 수 있게 한다. Linux에서의 빌드와 실제 Windows 실행 검증을 구분한다.

## 켜기
MAC 주소로 Wake-on-LAN 매직 패킷을 IPv4 브로드캐스트 UDP 9번 포트로 전송한다. 기본 브로드캐스트 주소는 255.255.255.255이며 필요하면 등록 시 수정한다. MAC 주소 형식을 검증한다. 화면은 '켜기 요청 전송'을 표시하며 전송만으로 부팅 성공이라고 표시하지 않는다. BIOS/UEFI Wake-on-LAN, 유선 랜카드의 Magic Packet, Windows 빠른 시작과 종료 전원 상태가 실제 동작에 영향을 준다. 최초 설정 안내와 현장 시험 절차를 제공한다.

## 끄기와 인증
에이전트는 자동 시작 Windows 서비스로 실행한다. HTTPS TCP 18765를 사용하고 방화벽은 사설·도메인 프로필의 LocalSubnet으로 제한한다. 설치 시 PC별 무작위 256비트 인증키와 자체 서명 TLS 인증서를 생성한다. 관리 앱은 명시적으로 가져온 인증 파일의 인증서 SHA-256 지문을 고정해 연결을 검증한다. 신뢰하지 않는 인증서·틀린 인증키는 거부한다. 인증키는 URL이나 로그에 넣지 않는다.
서버의 인증 자료와 개인키는 SYSTEM·Administrators만 접근하도록 파일 권한을 제한한다. 관리자 앱의 저장 인증키는 해당 Windows 사용자 계정의 DPAPI로 암호화한다. 인증 파일에는 비밀 값이 포함되므로 안전하게 전달하고 등록 후 보관·삭제하도록 안내한다.
인증된 상태 확인과 종료 요청만 제공한다. 임의 셸 명령·외부 명령 문자열은 받지 않는다. 종료는 직접 Windows API 또는 고정 인자로 된 OS 호출로 수행한다.

## 종료 안전성과 결과
종료 전에 선택 PC 이름과 수를 확인하는 창을 띄운다. 기본 종료 대기 시간은 30초이며 저장하지 않은 앱을 강제로 종료하지 않는다. UI는 '종료 예약됨'과 실제 서비스 연결 상태를 구분한다. 미저장 앱이 종료를 막을 수 있음을 안내한다. 제어 앱 자신의 PC를 끄는 경우 추가 확인한다.
상태 확인 실패는 '응답 없음'으로 표시하며 확정적인 전원 꺼짐으로 간주하지 않는다. 통신 시간 제한과 취소를 적용하며 한 PC 오류가 나머지 PC 처리를 막지 않는다.

## 설치와 구성
PowerShell 설치·제거 스크립트는 관리자 권한을 확인하고 Windows 서비스, 로컬 상태 디렉터리, 제한된 방화벽 규칙을 관리한다. 대상 PC의 기존 설정·인증 자료를 재설치 때 임의로 교체하지 않는다. 등록 정보는 사용자 LocalAppData 아래 저장한다. 소스·테스트에 실제 사무실 IP, 비밀번호, 개인 인증키를 포함하지 않는다.

## 검증
코어 단위 테스트: MAC 검증과 정확한 102바이트 매직 패킷, 로컬 UDP 전송 수신, 잘못된 입력 거부, 등록 저장·읽기, 인증 비교, 선택 대상별 결과 처리.
HTTPS 통합 테스트: 올바른 인증 성공, 틀린 인증키·다른 인증서 거부, 중복 종료 요청 처리, 상태 확인, 시간 초과. 종료 동작은 테스트 대역으로 치환해 개발 환경의 PC를 종료하지 않는다.
지원 SDK에서 솔루션 빌드, Windows x64 publish, 테스트를 실행한다. 실제 Windows 설치·DPAPI·서비스 권한·방화벽·WOL·OS 종료는 현장 Windows PC에서 별도 검증한다. 권한 없이 사무실 PC에 실제 종료 명령을 보내지 않는다.

## 완료 산출물과 한계
C# 솔루션·관리 앱·에이전트·단위 및 통합 테스트·배포/설치 스크립트·한국어 사용 문서. 가능하면 실행 가능한 Windows x64 게시 폴더를 ZIP으로 제공한다. GitHub에는 코드와 문서만 올리고 인증 자료는 제외한다.
실제 전원 켜짐은 하드웨어와 LAN 설정이 지원해야 하며, 강제 종료를 쓰지 않아 종료가 지연될 수 있다. 인터넷 외부 원격 제어는 범위 밖이다.
